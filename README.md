# Slyvoryn: Land and Botanical Supply Marketplace

Live product: https://slyvoryn.com

Slyvoryn connects verified land, harvesters, botanical resources and commercial buyers through one supply network.

## What it does

- Address to coordinates lookup (geocoding)
- Free state-by-state search of legal and botanical data
- Four entry paths: I need supply, I have supply, I have land, I can harvest
- Tiered subscriptions, and a fee that applies only when a real sale closes
- Built-in AI assistant

## Built with

A 17-phase build on AWS using serverless services.
